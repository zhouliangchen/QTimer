# 优化评估 · 1.8.0

日期：2026-10-21。范围：本地代码审查、可复现故障、合成故障测试和 Windows 原生运行验证。

优先度依据：可能打断演示、计时错误或设置丢失的问题优先修复；改变使用习惯、新增功能或暂未形成明显瓶颈的性能改造等待用户决定。

## 高优先度：已实施

| 项目 | 发现与影响 | 本次处理 |
| --- | --- | --- |
| 计时准确性 | 模拟系统时钟前跳 400 秒会让计时直接到期；暂停最多使用上一帧剩余时间 | 改用单调时钟；暂停即时计算剩余时间 |
| 设置不中断计时 | 仅保存字体通透度，也会从第 2 环节运行中重置到第 1 环节暂停 | 保留环节、截止点、运行状态和预警状态；只有环节定义变化才重置 |
| 配置可靠性 | 异常字段可造成启动类型错误；保存错误被吞掉；空流程可提交 | 规范化字段；禁止空流程；原子写入、备份、损坏文件保留与恢复；失败不关闭编辑窗口、不提交流程 |
| 放映联动稳定性 | 单次退出检测即暂停，瞬间漏检也可能中断计时 | 连续两次检测确认退出；短暂漏检不清除手动暂停意图 |
| 窗口位置可靠性 | 负坐标副屏被判作未设置；500 ms 保存延迟内退出可能丢失位置 | 支持负坐标；启动/屏幕切换时回收完全离屏的计时区；退出前刷新位置 |

保存链路同时减少了重复写入；没有修改快捷键时保留当前注册，避免不必要的解除与重新注册。

备份是最近一次可读取 JSON 的副本；备份路径不可写时不阻止主配置保存。磁盘本身不可写时会明确提示，不能保证强制结束进程后的保存。

环境：本机 Windows、Python 3.13.1、PySide6 6.12.0，Fusion 界面风格。数字是当前机器的局部测量，不代表其他电脑或长时间运行表现。

| --- | ---: | ---: | ---: |

扫描暂未显示明显瓶颈。设置页初始化有可感知的优化空间，可优先尝试字体列表复用、素材缩略图缓存和按需创建页面；不在本次擅自重构。配置落盘只发生在保存或拖动后的防抖保存，不跟随每一帧计时或滑块预览。
